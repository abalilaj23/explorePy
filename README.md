                Exploring Data with Python 

This project explores a large dataset using the pandas library in Python. It shows how to access specific rows and columns, making it easier to navigate even the largest datasets. It also includes various cleaning and preparation techniques, such as setting column data types, handling missing values, and more. The code here also creates queries, performs aggregations, and visualizes  data through plots.

So it includes:

-Work with Series and DataFrame objects

-Subset data using .loc, .iloc, and indexing operators

-Queries, grouping, and aggregation

-Manage missing, invalid, and inconsistent data

-Visualize datasets within a Jupyter Notebook

                Data
The data used here comes from FiveThirtyEight and includes NBA results over the years. It consists of 23 variables and more than 120,000 observations.
