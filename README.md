# Exploring Data with Python

## Project Overview

This project explores a large dataset using the **pandas** library in Python. It demonstrates how to access specific rows and columns, making it easier to navigate even the largest datasets. The project also covers various data cleaning and preparation techniques, such as setting column data types, handling missing values, and more. Additionally, the code creates queries, performs aggregations, and visualizes the data through plots.

### Key Features

- **Work with Series and DataFrame objects**: Learn how to interact with pandas' core data structures.
- **Subset data using `.loc`, `.iloc`, and indexing operators**: Filter and access specific portions of the dataset.
- **Queries, grouping, and aggregation**: Perform complex queries and aggregate data for analysis.
- **Manage missing, invalid, and inconsistent data**: Clean the dataset by handling missing or problematic data.
- **Visualize datasets within a Jupyter Notebook**: Create plots and visualizations to understand trends and patterns in the data.

## Data

The data used in this project comes from **FiveThirtyEight** and includes **NBA results over the years**. It consists of **23 variables** and over **120,000 observations**. This dataset provides insights into various aspects of NBA games and can be used for analysis of team performance, player statistics, and more.
